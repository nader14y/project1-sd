🌿 branch یعنی خطِ زمانیِ موازی

main      ───●────────────────●─── merge ──●───
               \             /
fix/names       ●───●───────/
روی branch کار می‌کنی، خراب می‌کنی، درست می‌کنی — و main دست‌نخورده می‌ماند. وقتی کارت تمام و سالم شد، برش می‌گردانی.

🔀 PR و کد ریویو

قاعده‌ی کلاس: هر ریویو حداقل یک کامنت دارد. «خوبه» کامنت نیست.
نوع کامنتمثال
❓ سؤال«اگر اسم خالی بگذارد چه می‌شود؟»
💡 پیشنهاد«این پیام را فارسی کنیم؟»
👏 تحسینِ مشخص«اینکه error را دوباره ننوشتی و همان پیامِ موتور را نشان دادی، عالیه»
و دکمه‌ی merge را نویسنده نمی‌زند — ریویوکننده می‌زند. حتی در شرکت‌های واقعی.
قانون ۸: main همیشه سالم و قابل‌بازی است؛
کار روی branch، و ورود به main فقط با ریویو.

💥 conflict

صفحه‌ی ۲ · وقتی دو نفر یک خط را عوض کرده‌اند
conflict یعنی خراب کردی؟ نه.
conflict یعنی دو نفر هم‌زمان کار کردند — یعنی تیم دارد کار می‌کند. اگر هیچ‌وقت conflict نگیرید، یعنی هم‌زمان کار نمی‌کنید.

🛠 مراحل حل

git switch fix/question-bank
git pull origin main          ← main‌ِ تازه را بیاور تو

   … در VS Code، هر ناحیه‌ی conflict را تصمیم بگیر …

pytest                        ← ⚠️ حتماً! موقع حل، راحت یک خط اضافه پاک می‌شود
git add game.py
git commit -m "Merge main into question bank fix"
git push
⭐ مهم‌ترین نکته‌ی این برگه
در conflictِ امروز، هر دو نسخه درست بودند — هر دو لاگ را در game.log می‌نوشتند. هیچ‌کس اشتباه نکرده بود.
git هیچ‌وقت نمی‌داند کدام درست است.
این یک تصمیمِ انسانی است.
⚠️ و Accept Both اینجا غلط است — دو تا basicConfig می‌شود. یکی را انتخاب کن، آن یکی را پاک.

⏪ سفر در زمان

دستورچه کار می‌کند
git restore <فایل> تغییرِ ذخیره‌نشده را دور بریز
git restore --source=<هش> -- <فایل> یک فایل را به نسخه‌ی یک commitِ قدیمی برگردان
git revert <هش> یک commitِ انجام‌شده را خنثی کن
چرا revert تاریخچه را پاک نمی‌کند؟
چون آن commit روی GitHub رفته و شاید هم‌تیمی‌ات pull کرده باشد. تاریخچه‌ای که دیگران دارند را نمی‌شود پاک کرد — ولی می‌شود تصحیحش کرد.
مثل دفتری که با خودکار نوشته شده: پاک نمی‌کنی، یک خط جدید می‌نویسی. 
git log --oneline        ← هشِ commitِ بد را پیدا کن
git revert a1b2c3d       ← یک commitِ تازه می‌سازد که عکسش را می‌کند
