🧩 شکل try / except

try:
    return Match(player1_name, player2_name, questions)   ← فقط خطی که ممکن است بترکد
except ValueError as error:                               ← نوعِ خطا، نه except خالی
    console.print(f"⛔ {error}", style="bold red")         ← واکنش: به کاربر بگو
    console.print("دوباره امتحان کن.")                     ← و بگو حالا چه کند
قاعدهچرا
try دورِ کمترین کد اگر کلِ تابع را بگیری، خطای چیزهای دیگر هم قاطی می‌شود
همیشه نوع‌دار (except ValueError) except: خالی یعنی «همه را قورت بده» — یعنی باگ را قایم کن
همیشه واکنش اگر جوابی برای «حالا چه کار کنم؟» نداری، اصلاً try نگذار
پیام را دوباره ننویس as error بگیر و همان را نشان بده — یک حقیقت، یک جا

🗂 نوعِ خطا کجاست؟ اولین کلمه‌ی صفحه‌ی قرمز

نوعیعنی
ValueErrorمقدار بی‌معنی است (دو هم‌نام، فایل خراب)
FileNotFoundErrorفایل نیست
json.JSONDecodeErrorفایل هست، ولی JSONِ سالم نیست
KeyErrorاین کلید در دیکشنری نیست
KeyboardInterruptکاربر Ctrl+C زد — این هم خطاست!

⚖️ جدولِ تصمیم — مهم‌ترین چیزِ این برگه

قبل از هر try، این سؤال را بپرس:
«بدون این داده می‌شود بازی کرد؟»
فایلبدونش می‌شود بازی کرد؟پس
questions.json❌ نه فریاد بزن و تمیز ببند
leaderboard.json✅ بله (حیف است، ولی می‌شود) از نو شروع کن و ادامه بده
مدیریت خطا یعنی تصمیم‌گیری — نه چسباندنِ try به همه‌جا.

📝 لاگ — دفترچه‌ای که برنامه برای خودش می‌نویسد

import logging

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
    handlers=[logging.FileHandler("game.log", encoding="utf-8")],
)
سطحیعنیمثال
logging.infoاین اتفاق افتادمسابقه شروع شد
logging.warningچیزی درست نبود، ولی ادامه دادیمنام تکراری، دوباره پرسیدیم
logging.errorنتوانستیم ادامه دهیمبانک سؤال خوانده نشد
logging.exceptionخطای پیش‌بینی‌نشده + کلِ ردِ خطاتورِ آخر
🔇 print یا log؟
print را کاربر می‌بیند  ·  log را تو.
دو کانالِ جدا. و لاگ ساعت دارد، سطح دارد، و روی کامپیوترِ یک نفرِ دیگر هم نوشته می‌شود.
و game.log در .gitignore می‌رود — تولید می‌شود، کد نیست (قانون ۶).

🥅 تورِ آخر — فقط یکی، در بیرونی‌ترین لایه

if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:
        console.print("\nخداحافظ!")                    ← Ctrl+C صفحه‌ی قرمز ندارد
    except Exception as error:
        console.print("⛔ یک مشکل پیش‌بینی‌نشده پیش آمد.")
        logging.exception("خطای پیش‌بینی‌نشده: %s", error)   ← همه‌چیز در game.log
«ولی گفتی exceptِ همه‌گیر بد است!» — فرقش در واکنش است: این یکی چیزی را قایم نمی‌کند، به کاربر می‌گوید و کامل گزارش می‌دهد. این تور است، نه سطل زباله.
قانون ۸: هر except نوع‌دار است و واکنش دارد؛
هر باگِ حل‌شده یک تستِ نگهبان می‌گیرد.
