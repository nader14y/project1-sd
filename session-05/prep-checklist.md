# چک‌لیست آماده‌سازی جلسه‌ی ۵ · کلاس ویندوزی

> **بزرگ‌ترین ریسک امروز احراز هویت GitHub است، نه آموزش.** اگر `push` گیر کند،
> نیمه‌ی دوم جلسه از دست می‌رود. آماده‌سازی زیر دقیقاً برای همین است.

---

## 🔴 سه کار حیاتی قبل از کلاس

### ۱. احراز هویت GitHub روی لپ‌تاپ‌ها

روی ویندوز، Git for Windows همراه **Git Credential Manager** نصب می‌شود و اولین `push`
یک پنجره‌ی مرورگر باز می‌کند برای ورود. اگر GCM نباشد، `push` گیر می‌کند.

روی **هر لپ‌تاپ** چک کنید:

```bat
git credential-manager --version
```

- [ ] جواب می‌دهد؟ اگر نه، Git for Windows را با گزینه‌های **پیش‌فرض** دوباره نصب کنید
- [ ] **پلن پشتیبان آماده باشد:** یک برگه با راهنمای Personal Access Token
      (GitHub → Settings → Developer settings → Personal access tokens (classic) →
      Generate → scope: `repo`). توکن **به‌جای رمز عبور** وارد می‌شود.
- [ ] ⚠️ خودتان یک‌بار روی یک repo تازه `push` کنید تا جریان ورود را از حفظ بدانید

### ۲. همه از قبل در مرورگر وارد GitHub شده باشند

دعوت collaborator باید سر کلاس **قبول** شود. اگر کسی رمز GitHubش را یادش نباشد،
۱۰ دقیقه از جلسه می‌رود.

- [ ] در پیام گروه کلاس، **شب قبل** بفرستید: «فردا حساب GitHub لازم است.
      همین امشب در مرورگر لپ‌تاپت وارد github.com شو و مطمئن شو رمزت را داری.»
- [ ] **نام کاربری GitHub همه را از قبل جمع کنید** (در یک فایل، به‌ترتیب تیم) —
      سر کلاس برای دعوت collaborator لازم می‌شود و پرسیدنش وقت می‌برد

### ۳. پلن B آفلاین

اگر اینترنت کلاس قطع شد، بلوک GitHub با یک فلش قابل اجراست
(`git clone --bare` روی فلش به‌عنوان «خانه‌ی مشترک»). جزئیاتش در راهنمای مربی.

- [ ] یک فلش خالی همراهتان باشد
- [ ] **یک‌بار خودتان تستش کنید** — سه دستورش را در راهنما نوشته‌ام

## ۵ دقیقه اول کلاس

- [ ] مسابقه‌ی راه‌اندازی (بخشی از خود جلسه است، دقیقه‌ی ۰ تا ۵)

      برایش بی‌معناست

## چیزهایی که **نباید** انجام دهید

- ❌ `git reset --hard` — خطرناک‌ترین ابزار git را دست تازه‌کار ندهید
- ❌ `git rebase`، `stash`، `cherry-pick`، `tag` — هیچ‌کدام امروز نه
- ❌ **conflict** — عمداً امروز نه. امروز به‌اندازه‌ی کافی تازگی دارد؛
      جلسه‌ی ۸ با تقسیم کار واقعی روی `engine.py` و `game.py`، conflict خودش پیش می‌آید
- ❌ Pull Request — جلسه‌ی ۸
- ❌ عمومی‌کردن repo — جلسه‌ی ۱۱
- ❌ SSH key — پیچیده‌تر از HTTPS و امروز لازم نیست
- ❌ GitHub Desktop یا پنل Source Control برای push — امروز با ترمینال،
      تا بفهمند زیر دکمه‌ها چه می‌گذرد
