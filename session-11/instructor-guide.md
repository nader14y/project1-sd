## ⭐ فیکس ۱ (دقیقه‌ی ۱۰ تا ۱۶) — `app_dir()`: مهم‌ترین ده خطِ امروز

**اول درد را نشان بدهید.** بپرسید:

> «وقتی `python game.py` می‌زنی، ترمینالت داخل پوشه‌ی پروژه است و
> `questions.json` همان‌جاست. حالا exe را روی **دسکتاپ** بگذار و دوبار کلیک کن.
> پایتون کجا دنبال `questions.json` می‌گردد؟»

جواب: **در دسکتاپ.** و آنجا نیست.

در `storage.py`:

```python
import sys
from pathlib import Path


def app_dir() -> Path:
    """پوشه‌ای که برنامه واقعاً در آن است — چه پایتون باشد، چه .exe"""
    if getattr(sys, "frozen", False):
        return Path(sys.executable).parent      # کنار فایل exe
    return Path(__file__).parent                # کنار فایل پایتون


QUESTIONS_PATH = app_dir() / "questions.json"
LEADERBOARD_PATH = app_dir() / "leaderboard.json"
```

**دو نکته، و اولی قشنگ‌ترین ایده‌ی امروز است:**

- **`getattr(sys, "frozen", False)`** — «این خط یعنی: *برنامه از خودش می‌پرسد الان
  داخل exe هستم یا کد؟* `sys.frozen` فقط وقتی وجود دارد که PyInstaller بسته‌بندی‌اش
  کرده باشد. پس برنامه **خودش می‌فهمد** در کدام حالت است.»
- **`Path(__file__).parent` به‌جای مسیر نسبی** — «از این به بعد فایل‌ها را کنارِ
  **خودِ برنامه** می‌گردیم، نه کنارِ جایی که اتفاقاً ترمینال آنجاست.»

## فیکس ۲ (دقیقه‌ی ۱۶ تا ۱۹) — پیامِ آدمیزاد به‌جای دیوارِ قرمز

`QuestionBank()` الان **بیرونِ** `try` صدا زده می‌شود. اگر فایل نباشد → دیوار قرمز.

در `storage.py`:

```python
        if not Path(path).exists():
            raise FileNotFoundError(f"فایل questions.json پیدا نشد: {path}")

        try:
            with open(path, "r", encoding="utf-8") as f:
                data = json.load(f)
        except json.JSONDecodeError as error:
            raise ValueError(
                f"فایل questions.json خراب است (خط {error.lineno}): {error.msg}"
            ) from error
```

و در `game.py` → `main()`:

```python
    try:
        bank = QuestionBank()
    except FileNotFoundError as error:
        console.print(f"⛔ {error}", style="bold red")
        console.print("فایل questions.json باید کنار برنامه باشد.", style="yellow")
        input("\nEnter برای بستن… ")      # ← ⭐ این خط را توضیح بدهید
        return
```

⭐ **روی `input("Enter برای بستن…")` بایستید** — نکته‌ی ظریفِ دنیای exe:

> «وقتی روی exe دوبار کلیک می‌کنی و برنامه تمام می‌شود، **پنجره فوری بسته می‌شود**.
> کاربر حتی فرصت نمی‌کند پیام را بخواند! این یک خط، پنجره را نگه می‌دارد.
> در حالت `python game.py` اصلاً لازم نبود — ولی حالا برنامه‌ی ما یک **محصول** است.»

## فیکس ۳ (دقیقه‌ی ۱۹ تا ۲۲) — نام تکراری، و تورِ ساکت

الان اگر دو نام یکسان بدهند، `except Exception` سراسریِ شما خطا را می‌گیرد،
**لاگ می‌کند، و هیچ به کاربر نمی‌گوید** — کاربر فقط می‌بیند که برگشت سر منو.

دو تغییر کوچک: تابع `ask_names` که تا قبول‌شدن دوباره می‌پرسد، و اضافه‌کردنِ یک
پیام به تورِ سراسری.

> «لاگ برای **ما**ست. ولی کاربر هم باید **یک جمله** ببیند. تورِ آخر هر دو را لازم دارد.»

**⏸ نقطه‌ی توقف:** `pytest` سبز است؟ (قانون ۷) بعد commit.

# ۲۲ تا ۵۰ — 📦 ساختِ `.exe`

## دقیقه‌ی ۲۲ تا ۲۶ — PyInstaller چه می‌کند؟

روی تخته بکشید:

```
   game.py + engine.py + storage.py          ┐
   پایتون ۳.۱۳                                ├──→  QuizBattle.exe  (۱۲ مگابایت)
   rich و همه‌ی کتابخانه‌ها                    ┘
```

> «PyInstaller **همه‌چیز را در یک فایل می‌گذارد** — حتی خودِ پایتون را.
> برای همین ۱۲ مگابایت است. کامپیوترِ مقابل هیچ‌چیز لازم ندارد.»

```bat
pip install pyinstaller
pip freeze > requirements.txt
```

## دقیقه‌ی ۲۶ تا ۴۲ — build

```bat
pyinstaller --onefile --clean --name QuizBattle game.py
```

| گزینه | یعنی |
|---|---|
| `--onefile` | همه‌چیز در **یک** فایل، نه یک پوشه‌ی شلوغ |
| `--clean` | از نوِ نو بساز (اگر قبلاً خراب ساخته شد) |
| `--name` | اسم فایل خروجی |

⏳ **۱ تا ۳ دقیقه طول می‌کشد.** در این فاصله بین میزها بچرخید.
خروجی در پوشه‌ی `dist/` می‌نشیند.

**و بلافاصله `.gitignore`:**

```
build/
dist/
*.spec
```

> ## «خروجیِ ساخت، کد نیست.»
> «همان قانون ۶، این‌بار برای خروجیِ build: هر چیزی که **تولید می‌شود**، در git نمی‌رود.
> فردا دوباره ساخته می‌شود.»

## ⭐ دقیقه‌ی ۴۲ تا ۵۰ — آزمونِ واقعی

**این لحظه‌ی جلسه است. کوچکش نکنید.**

```
۱) فایل QuizBattle.exe را از dist بردار
۲) ببرش روی دسکتاپ — یعنی یک پوشه‌ی کاملاً بی‌ربط
۳) دوبار کلیک کن
```

**اگر فیکس ۱ را درست زده باشند، اجرا نمی‌شود** — چون `questions.json` آنجا نیست،
ولی حالا **پیام آدمیزاد** می‌دهد نه دیوار قرمز. 🎉 **این خودش یک پیروزی است:**

> «ببینید! نمُرد. گفت چه چیزی لازم دارد. **این فرقِ یک برنامه با یک محصول است.**»

حالا `questions.json` را هم کنارش بگذارید → بازی بالا می‌آید. 📸 **عکس بگیرید.**

⚠️ **اگر `questions.json` کنارش بود و باز هم `FileNotFoundError` داد:** یعنی فیکس
`app_dir()` انجام نشده یا بعد از آن build نشده. دوباره build کنند.

# 🪜 نردبان حذف

۲۸ دقیقه برای build گرفته‌ام چون روی ۸ لپ‌تاپ کند است. اگر سریع‌تر پیش رفت،
وقتِ اضافه را به **تورنمنت** بدهید، نه به محتوای تازه.

1. ~~فیکس ۳ (نام تکراری)~~ → `except` سراسری الان هم نمی‌گذارد بمیرد (۳ دقیقه)
2. ~~قوسِ دوره (۰ تا ۱۰)~~ → به ۴ دقیقه کم کنید، فقط جدول (۶ دقیقه)
3. ~~`build.bat`~~ → دستورها را دستی بزنند (۳ دقیقه)
4. ~~شکستنِ بازیِ تیم مقابل~~ → فقط بازی کنند (۵ دقیقه)

**چهار چیزی که هرگز حذف نمی‌شوند:**
- **فیکس `app_dir()`.** بدونش exe کار نمی‌کند و کلِ جلسه بی‌نتیجه است.
- **آزمونِ دوبار کلیک روی دسکتاپ.** لحظه‌ی «واو» همین است.
- **فلش و بردنِ بازی به خانه.** چیزی که امروز با خودشان نبرند، هفته‌ی بعدی ندارد.
- **پوستر ۹ قانون و «هیچ‌کدام درباره‌ی پایتون نیست».** این جمع‌بندیِ کلِ دوره است.
