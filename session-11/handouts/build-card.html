جلسه‌ی ۱۱ · Quiz Battle · روزِ تحویل
⚠️ اول این، بعد build
بدون این ده خط، .exe ساخته می‌شود ولی با دوبار کلیک می‌میرد، چون questions.json را پیدا نمی‌کند. در storage.py: 
import sys
from pathlib import Path


def app_dir() -> Path:
    """پوشه‌ای که برنامه واقعاً در آن است — چه پایتون باشد، چه exe"""
    if getattr(sys, "frozen", False):
        return Path(sys.executable).parent      # کنار فایل exe
    return Path(__file__).parent                # کنار فایل پایتون


QUESTIONS_PATH = app_dir() / "questions.json"
LEADERBOARD_PATH = app_dir() / "leaderboard.json"
sys.frozen فقط وقتی وجود دارد که داخل exe باشیم — یعنی برنامه از خودش می‌پرسد الان exe هستم یا کد.

🛠 ساخت — سه دستور

venv\Scripts\activate          ← حتماً! وگرنه exe چهارصد مگابایت می‌شود
pip install pyinstaller
pip freeze > requirements.txt

pyinstaller --onefile --clean --name QuizBattle game.py
گزینهیعنی
--onefileهمه‌چیز در یک فایل، نه یک پوشه‌ی شلوغ
--cleanاز نوِ نو بساز (اگر قبلاً خراب ساخته شد)
--nameاسم فایل خروجی
⏳ بارِ اول ۱ تا ۳ دقیقه طول می‌کشد. خروجی در پوشه‌ی dist\ است.

🎁 بسته‌ی تحویل — سه فایل، نه یکی

release\
├── QuizBattle.exe      ← برنامه
├── questions.json      ← محتوای محصول، همراهش می‌رود
└── README.md           ← چطور کار می‌کند
و leaderboard.json را نگذار — آن داده‌ی بازیکن است و خودش ساخته می‌شود. (همان قانون ۶، این‌بار موقع تحویل.)

✅ آزمونِ واقعی

  • فایل exe را روی دسکتاپ ببر — یعنی یک پوشه‌ی کاملاً بی‌ربط
  • دوبار کلیک کن → باید بگوید questions.json نیست، با پیام آدمیزاد، نه دیوارِ قرمز
  • questions.json را هم کنارش بگذار → بازی بالا می‌آید 🎉
  • روی لپ‌تاپ یک نفرِ دیگر امتحانش کن
  • یک مسابقه‌ی کامل بازی کن و ببین leaderboard.json کنارِ exe ساخته می‌شود
