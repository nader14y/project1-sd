## 🔴 چهار کار حیاتی قبل از کلاس

### ۱. ⭐ خودتان یک‌بار کاملاً build کنید — بدون این، کلاس را از دست می‌دهید

```bat
venv\Scripts\activate
pip install pyinstaller
pyinstaller --onefile --clean --name QuizBattle game.py
```

- [ ] build تمام شد و `dist\QuizBattle.exe` ساخته شد
- [ ] **عمداً بدون فیکس `app_dir()` یک‌بار امتحانش کنید** — exe را روی دسکتاپ ببرید و
      دوبار کلیک کنید. باید `FileNotFoundError` بدهد. **شکل خطا را ببینید**، چون
      سر کلاس همین را نشان می‌دهید
- [ ] حالا فیکس `app_dir()` را بزنید، **دوباره** build کنید، و ببینید کار می‌کند
- [ ] exe را روی **یک لپ‌تاپ دیگر** (ترجیحاً بدونِ پایتون) امتحان کنید
- [ ] ببینید SmartScreen چه می‌گوید، تا سر کلاس غافلگیر نشوید

> ⏱ **زمان‌سنجی کنید:** build روی لپ‌تاپ شما چند ثانیه طول کشید؟ روی لپ‌تاپ بچه‌ها
> احتمالاً کندتر است. این عدد را بدانید تا بتوانید جلسه را مدیریت کنید.

### ۲. فلش — مهم‌ترین وسیله‌ی امروز

امروز بچه‌ها باید بازیشان را **با خودشان ببرند**. اگر فلش نباشد، جلسه‌ی آخر
بدون نتیجه‌ی ملموس تمام می‌شود.

- [ ] **یک فلش با فضای کافی** (هر تیم ~۱۵ مگابایت)
- [ ] یا پوشه‌ی اشتراکی شبکه، اگر مطمئن‌تر است
- [ ] `live-code/build.bat` را روی فلش بگذارید
- [ ] اگر می‌توانید، چند فلش کوچک بخرید و **هدیه بدهید** — بازی‌شان رویش

### ۳. نصب آفلاین PyInstaller (برنامه‌ی B)

اگر شبکه کند باشد، ۸ لپ‌تاپ منتظر می‌مانند:

```bat
pip download pyinstaller -d wheels
```

- [ ] پوشه‌ی `wheels` روی فلش
- [ ] تست شد: `pip install --no-index --find-links=wheels pyinstaller`

### ۴. پروژه‌ی مرجعِ خودتان

- [ ] یک پروژه‌ی سالمِ پایان جلسه‌ی ۱۰ با فیکس‌های امروز، آماده روی لپ‌تاپ خودتان
- [ ] `live-code/storage_complete.py` و `game_complete.py` روی فلش — برای تیم‌های عقب‌مانده
- [ ] `starting_point.py` جلسه‌ی ۳ را پیدا کنید — دقیقه‌ی ۰ تا ۱۰ کنار پروژه‌ی امروز
      نشانش می‌دهید

## چیزهایی که **نباید** انجام دهید

- ❌ **اجازه‌ی build قبل از فیکس `app_dir()`** — دو بار build یعنی ده دقیقه تلف
- ❌ build از بیرونِ `(venv)` — exe چهارصد مگابایتی
- ❌ شروعِ هر مبحث تازه‌ای (branch، sqlite، pygame) — امروز جای یادگیری نیست،
      جای **تحویل** است
- ❌ تمام‌شدن جلسه بدون اینکه فلش دستِ بچه‌ها باشد
- ❌ رد شدن از آزمونِ دوبار کلیک روی دسکتاپ
