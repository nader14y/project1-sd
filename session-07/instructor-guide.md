## دقیقه‌ی ۷ تا ۱۳ — با هم بخوانید، خط به خط (۶ دقیقه)

روی پرده باز کنید و **چهار جا انگشت بگذارید**:

```python
    def __init__(self, path: str = LEADERBOARD_PATH) -> None:
        self._path = Path(path)
        self._data: dict[str, dict[str, int]] = {}

        if self._path.exists():          # ①
            with open(self._path, encoding="utf-8") as f:
                self._data = json.load(f)
```

**① `if self._path.exists()`** — بپرسید: **«اولین باری که بازی اجرا می‌شود، این فایل
هست؟»** → نه. «و این خطا نیست، طبیعی است. برنامه‌ی خوب، بارِ اول هم کار می‌کند.»

```python
        for name, points in [(player1, score1), (player2, score2)]:
            if name not in self._data:
                self._data[name] = {"wins": 0, "points": 0}      # ②
            self._data[name]["points"] += points
```

**② دیکشنری داخل دیکشنری** — یک دقیقه رویش بایستید و شکلش را روی تخته بکشید.
اینجا جای گم‌شدن است:

```
_data  →  "علی"  →  {"wins": 2, "points": 45}
       →  "رضا"  →  {"wins": 0, "points": 30}
```

```python
        self._save()                     # ③
```

**③** بپرسید: **«اگر این خط نباشد چه می‌شود؟»** → همه‌چیز در RAM درست است، و به‌محض
بستن برنامه دود می‌شود. «تخته‌وایت‌برد و دفتر، یادتان هست؟»

```python
    def _save(self) -> None:
        with open(self._path, "w", encoding="utf-8") as f:      # ④
            json.dump(self._data, f, ensure_ascii=False, indent=2)
```

**④ `"w"`** — «حالت نوشتن. و بدانید: `"w"` فایل قبلی را **کامل پاک می‌کند** و از نو
می‌نویسد. برای همین اول تمام دفتر را در `_data` خواندیم.»

## ⭐ دقیقه‌ی ۱۳ تا ۱۶ — نمایشِ `ع` (۳ دقیقه، از دستش ندهید)

**عمداً `ensure_ascii=False` را از خط `json.dump` بردارید**، یک مسابقه‌ی سریع ثبت کنید،
و `leaderboard.json` را باز کنید:

```json
{"علی": {"wins": 0, "points": 30}, ...}
```

بپرسید **«اسم علی کجاست؟»** بگذارید بخندند.

> «هست! همین است. JSON محافظه‌کار است: فرض می‌کند شاید طرفِ مقابل فارسی نفهمد،
> پس همه‌چیز را به کدِ انگلیسی ترجمه می‌کند.»

حالا هر دو را برگردانید و دوباره اجرا کنید:

> «`ensure_ascii=False` می‌گوید *فارسی را فارسی بنویس*، و `indent=2` می‌گوید
> *خوانا بنویس* — چون این فایل را **آدم** هم می‌خواند.»

## دقیقه‌ی ۳۲ تا ۳۸ — اولین تست، با هم تایپ می‌شود

فایل `tests/test_engine.py`:

```python
import pytest

from engine import Match, Question, ROUNDS


def make_questions(power_up=None):
    return [Question("۲+۲؟", ["4", "5", "6", "7"], "A", power_up) for _ in range(ROUNDS)]


def make_match(power_up=None):
    return Match("علی", "رضا", make_questions(power_up))


def test_correct_answer_gives_points():
    m = make_match()
    m.start_round()
    m.submit("علی", "A", 5.0)
    m.submit("رضا", "B", 8.0)
    m.resolve_round()

    assert m.score_of("علی") == 13      # ۱۰ + ۳ بونوس (تنها درست‌جواب)
    assert m.score_of("رضا") == 0
```

**سه نکته:**
- **`assert`** — «یعنی *ادعا می‌کنم*. اگر راست بود، هیچ اتفاقی نمی‌افتد. اگر دروغ بود، داد می‌زند.»
- **`make_match`** — «اسمش با `test_` شروع نمی‌شود، پس pytest اجرایش نمی‌کند. فقط کمک‌کار است.»
- **هیچ `print`ی در تست نیست** — «تست حرف نمی‌زند. یا سبز است، یا قرمز.»

# ۶۲ تا ۸۰ — تمرین اصلی: قواعدِ بازیِ خودت را سند کن

لیست را روی تخته بنویسید. **هر تیم تا جایی که می‌رسد پیش می‌رود** — کف قبولی ۶ تست است:

| # | تست | نکته |
|---|---|---|
| ۱ | جواب غلط → صفر | گرم‌کردن |
| ۲ | هر دو غلط → بونوس به هیچ‌کس نمی‌رسد | `if correct_players:` را سند می‌کند |
| ۳ | حرف کوچک و فاصله (`" a "`) → درست حساب شود | `.strip().upper()` |
| ۴ | ⚡ دوبل: چند امتیاز؟ | **↓ پایین بخوانید** |
| ۵ | مساوی → `winner() is None` | همان تمرین جلسه‌ی ۴ |
| ۶ | نام تکراری → `pytest.raises(ValueError)` | باگ عمدی جلسه‌ی ۴ |
| ۷ | بازیکن غریبه → `ValueError` | نگهبان جلسه‌ی ۴ |
| ۸ | سؤال با ۳ گزینه → `ValueError` | نگهبان جلسه‌ی ۶ |

## ⭐ تست شماره‌ی ۴ را جدی بگیرید — این «تصمیم» است، نه «جواب»

روی تخته بنویسید و **بگذارید هر تیم خودش تصمیم بگیرد**:

```
علی درست جواب داد و سریع‌ترین هم بود. سؤال ⚡ دوبل بود.
     (۱۰ + ۳) × ۲ = ۲۶    یا    ۱۰ × ۲ + ۳ = ۲۳    ؟
```

> «هیچ‌کدام غلط نیست. **قاعده‌ی بازیِ شماست.** ولی وقتی انتخابش کردید، تست بنویسید —
> چون از آن لحظه، **تست، قانونِ نوشته‌شده‌ی بازیِ شماست.** سه هفته‌ی دیگر که یادتان
> رفت چه تصمیمی گرفتید، تست یادش هست.»

*(کدِ فعلی ما اول بونوس می‌دهد بعد دوبل می‌کند → ۲۶.)*

**و `pytest.raises` را یک‌بار روی پرده نشان بدهید:**

```python
def test_two_players_cannot_have_the_same_name():
    with pytest.raises(ValueError):
        Match("علی", "علی", make_questions())
```

> «یعنی: *ادعا می‌کنم این خط خطا می‌دهد.* اگر خطا **نداد**، تست قرمز می‌شود.
> بله — گاهی خطا دادن، همان چیزی است که می‌خواهیم.»

🎯 **تست‌ها معمولاً حداقل یک باگ واقعی پیدا می‌کنند.** اگر پیدا شد، **بزرگش کنید:**
> «ربات اولین شکارش را کرد — قبل از اینکه وسط تورنمنت والدین پیدا شود.»
