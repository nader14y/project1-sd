بخش ب — 🤖 پنج تست دیگر

  1. این پنج تست را به tests/test_engine.py اضافه کن:
    ۱) جواب غلط → صفر امتیاز  ·  ۲) هر دو غلط → بونوس به هیچ‌کس
    ۳) " a " با فاصله و حرف کوچک → درست حساب شود  ·  ۴) مساوی → winner() is None
    ۵) بازیکن غریبه → pytest.raises(ValueError)
  2. یک فایل تازه بساز: tests/test_storage.py — و تابلوی امتیاز را تست کن. 
    def test_the_leaderboard_survives_a_restart(tmp_path):
    path = str(tmp_path / "leaderboard.json")

    board = ScoreBoard(path)
    board.record("سارا", "علی", 30, "سارا", 39)

    again = ScoreBoard(path)          # انگار برنامه بسته و باز شد
    assert dict(again.top(5))["سارا"] == {"wins": 1, "points": 39}
    ⚠️ حتماً tmp_path — وگرنه تست، رده‌بندی واقعی خودت را خراب می‌کند. دو تست دیگر هم بنویس: جمع‌شدن امتیاز در دو مسابقه، و مساوی (برد ثبت نشود).
  3. یک اسکرین‌شات از pytest -v سبز بگیر و بیاور.

  2. یک قاعده در بازی‌ات نام ببر که هیچ تستی ندارد. اگر فردا خراب شود، چطور می‌فهمی؟
قبل از تحویل، چک کن
  • pytest سبز است و ۱۱ تست یا بیشتر دارم
  • منو کار می‌کند و گزینه‌ی رده‌بندی، رده‌بندی را نشان می‌دهد
  • تست‌های ScoreBoard همه tmp_path دارند
  • بعد از اجرای تست‌ها، leaderboard.json واقعی من دست‌نخورده است
  • هر commit را بعد از سبز شدن pytest زدم (قانون ۷)
  • git push شده
⭐ اختیاری
یک باگ واقعی در بازی‌ات پیدا کن، اول یک تست بنویس که قرمز شود، بعد کد را درست کن تا سبز شود. این کار اسم دارد و حرفه‌ای‌ها مدام انجامش می‌دهند.
🔮 برای جلسه‌ی بعد
