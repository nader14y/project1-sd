🐞 پنج خطای رایج — و شکل دقیقشان

خطایی که می‌بینییعنی چهچطور پیدا کنی
Expecting ',' delimiter بین دو قلم، ویرگول جا افتاده Shift+Alt+F
بزن. جایی که مرتب نشد، همان‌جاست.

و خطا را از پایین به بالا بخوان — شماره‌ی خط، آخرِ پیام است.
Expecting property name
enclosed in double quotes		 یا ' نوشته‌ای به‌جای "،
یا بعد از آخرین قلم ویرگول گذاشته‌ای
Expecting value None نوشته‌ای به‌جای null
Unterminated string یک " را نبسته‌ای
Extra data ] پایانی جا افتاده یا زیادی است
⚠️ قانونِ بی‌استثنا — هر جا فایل باز می‌کنیم
open(path, encoding="utf-8")                       # خواندن
json.dump(data, f, ensure_ascii=False, indent=2)   # نوشتن
  • encoding="utf-8" نباشد → روی ویندوز فارسی خراب می‌شود
  • ensure_ascii=False نباشد → اسمت می‌شود علی
  • indent=2 نباشد → کل فایل یک خط می‌شود و git diff بی‌فایده
