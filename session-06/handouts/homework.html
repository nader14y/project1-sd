بخش د — git

  1. کار بالا را در حداقل ۳ commit جدا انجام بده و push کن. 
    git add questions.json
git commit -m "Add 10 questions across 3 categories"
git push
    و git status بزن: مطمئن شو leaderboard.json در لیست نیست — چون در .gitignore است.
قبل از تحویل، چک کن
  • بانک سؤالم ۱۵ سؤال یا بیشتر دارد و بازی بدون خطا اجرا می‌شود
  • منو کار می‌کند و گزینه‌ی رده‌بندی، رده‌بندی را نشان می‌دهد
  • برنامه را بستم و باز کردم — رده‌بندی ماند
  • leaderboard.json را باز کردم و اسم‌ها فارسی بودند، نه ع
  • git status تمیز است و push شده
  • هر سه سؤال طراحی را روی برگه جواب داده‌ام

🔮 برای جلسه‌ی بعد
یک سؤال با خودت ببر: از کجا می‌دانی همین الان بونوس سرعت درست کار می‌کند؟ هر بار باید یک مسابقه‌ی کامل بازی کنی تا مطمئن شوی چیزی نشکسته؟ جلسه‌ی بعد، کامپیوتر این کار را در یک ثانیه برایت می‌کند.
