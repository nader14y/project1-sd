# ۱۲ تا ۲۲ — قالب `questions.json`

## دقیقه‌ی ۱۲ تا ۱۶ — قالب روی تخته (قراردادِ کلِ کلاس)

این را روی تخته بنویسید و **بگویید که قرارداد است، نه سلیقه**:

```json
[
  {
    "text": "پایتخت ژاپن کدام است؟",
    "options": ["توکیو", "کیوتو", "اوساکا", "سئول"],
    "correct": "A",
    "power_up": null,
    "category": "جغرافیا"
  }
]
```

> «همه‌ی کلاس **دقیقاً** این قالب را دارد. چرا؟ چون جلسه‌ی ۸ سؤال‌های همدیگر را
> برمی‌دارید و به هم PR می‌دهید. اگر قالب هر تیم فرق کند، هیچ‌کدام کار نمی‌کند.»

**پنج نکته‌ی سریع** (هر کدام ۲۰ ثانیه، تندتند):

- `[ ]` بیرون، `{ }` برای هر سؤال — «لیستی از سؤال‌ها».
- **`"` همیشه دوتایی است، هرگز `'`** — JSON با پایتون فرق دارد. اولین خطای امروز همین است.
- **آخرین قلم، ویرگول ندارد.** دومین خطای امروز همین است.
- `null` نه `None`، و `null` بدون گیومه — «JSON زبان پایتون نیست؛ **زبان بین‌همه** است.»
- `"correct": "A"` — حرف، نه عدد. همان چیزی که موتور می‌فهمد.

**و یک سؤال که نمی‌خواهد جواب بدهید، فقط کاشتنش کافی است:**
> «به نظرتان چرا یک قالبِ مشترک اختراع کرده‌اند که هم پایتون بفهمد، هم جاوااسکریپت،
> هم گوشیِ شما؟» 🌱

# ۲۲ تا ۴۰ — 📒 `storage.py`: جعبه‌ی سوم

## دقیقه‌ی ۲۲ تا ۲۷ — ⭐ مهم‌ترین پنج دقیقه‌ی مفهومیِ امروز

**این را با یک سؤال شروع کنید و منتظر بمانید.** قانون ۴ روی دیوار است:
«کد جدید اول جواب می‌دهد: مغز است یا دهان؟»

> «کدی که می‌خواهد فایل `questions.json` را باز کند و بخواند — کجا برود؟ **مغز، یا دهان؟**»

کلاس دو دسته می‌شود، و **هر دو دسته دلیل خوبی دارند**. بگذارید دو دقیقه بحث کنند،
و استدلال‌ها را روی تخته بنویسید:

| «بگذاریم در مغز» | «بگذاریم در دهان» |
|---|---|
| سؤال، دادهٔ بازی است؛ مغز صاحب قواعد است | مغز که print ندارد، پس با دنیای بیرون کار نمی‌کند |
| — | ولی دهان کارش حرف‌زدن است، نه فایل خواندن |

بعد **جوابِ سوم** را بدهید:

> ## هیچ‌کدام.

> «معیارِ جلسه‌ی ۴ یادتان هست؟ *چیزهایی که به یک دلیل عوض می‌شوند کنار هم.*
> خواندن فایل، وقتی عوض می‌شود که **جای فایل یا شکل فایل** عوض شود — نه وقتی قاعده‌ی
> بازی عوض شود، و نه وقتی رنگ‌ها عوض شوند. **یک دلیلِ سوم. یعنی یک جعبه‌ی سوم.**»

و نقشه‌ی تخته را کامل کنید:

```
engine.py    🧠 مغز       → قواعد، امتیاز، برنده        (نه print، نه input، نه فایل)
game.py      👄 دهان      → نمایش، ورودی، رنگ، کرنومتر
storage.py   📒 دفتردار   → می‌رود سر قفسه می‌آورد، و در دفتر می‌نویسد   ← امروز
```

**دو جمله‌ی مربی که این لحظه را قفل می‌کند:**

> «امروز من نگفتم فایل سوم بسازید. **معیار** گفت. من فقط سؤال را پرسیدم.»

> «و یادتان باشد چرا امروز و نه جلسه‌ی ۴: چون جلسه‌ی ۴ این درد را **نداشتیم**.
> فایل تازه، جوابِ یک دردِ واقعی است، نه احتیاطِ از پیش.»

🧑‍🏫 اگر کسی گفت «پس چرا `QuestionBank` و `ScoreBoard` هر دو در یک فایلند؟ آن‌ها هم
دو کار جدایند!» — **درست دیده و تحسینش کنید:** «حق داری. ولی هنوز **درد** ندارد.
روزی که داشت، دو فایلش می‌کنیم. همان قاعده، این‌بار علیه خودم.» 🌱

## دقیقه‌ی ۳۰ تا ۴۰ — `QuestionBank`

اسکلت `live-code/storage_skeleton.py` را کپی می‌کنند، اسمش `storage.py`.

```python
import json
import random
from pathlib import Path

from engine import Question, ROUNDS

QUESTIONS_PATH = "questions.json"


class QuestionBank:
    def __init__(self, path: str = QUESTIONS_PATH) -> None:
        with open(path, encoding="utf-8") as f:      # ← encoding را جا نیندازید
            raw = json.load(f)

        self._questions: list[Question] = []
        for item in raw:
            self._questions.append(
                Question(
                    item["text"],
                    item["options"],
                    item["correct"],
                    item.get("power_up"),
                )
            )

    def count(self) -> int:
        return len(self._questions)

    def pick(self, n: int = ROUNDS) -> list[Question]:
        if self.count() < n:
            raise ValueError(
                f"بانک سؤال {self.count()} سؤال دارد؛ برای یک مسابقه {n} سؤال لازم است"
            )
        return random.sample(self._questions, n)
```

**پنج نکته، و اولی از همه مهم‌تر است:**

- ⚠️ **`encoding="utf-8"`** — روی ویندوز، بدون این، فارسی خراب می‌شود یا برنامه
  `UnicodeDecodeError` می‌دهد. **قانونِ بی‌استثنا:** «هر جا فایل باز می‌کنیم،
  `encoding="utf-8"`.» روی تخته بنویسید. امروز چهار بار تکرارش کنید.
- **`json.load(f)` چه می‌دهد؟** بپرسید و منتظر بمانید. جواب: **لیستی از دیکشنری‌ها**.
  «JSON روی دیسک، *نوشته* است. `json.load` آن نوشته را به لیست و دیکشنریِ پایتون
  ترجمه می‌کند.» این جمله را بگویید، مفهوم مرکزی امروز است.
- **حلقه‌ی تبدیل** — «دیکشنری، سؤال نیست. سؤالِ ما `Question` است، که `is_correct` دارد.
  این حلقه، **داده را به شیء تبدیل می‌کند**. مرزِ بین فایل و برنامه، همین‌جاست.»
- **`item.get("power_up")` نه `item["power_up"]`** — «`get` یعنی اگر این کلید نبود،
  `None` بده و خطا نده.» بپرسید: «چرا برای `text` از `get` استفاده نکردیم؟»
  → «چون سؤال بدون متن، سؤال نیست. ولی سؤال بدون قدرت ویژه، سؤال است.» 🎓
- **`random.sample`** — «`sample` یعنی بدون تکرار. اگر `choices` می‌نوشتیم، ممکن بود
  یک سؤال دو بار در یک مسابقه بیاید.» و بعد بلند بگویید:
  **«از الان هر مسابقه‌ی شما با مسابقه‌ی قبلی فرق دارد.»**

بعد `game.py` را وصل کنند (این کپی‌پیست است، سه خط):

```python

bank = QuestionBank()
console.print(f"[dim]بانک سؤال: {bank.count()} سؤال[/dim]\n")

```

و **لیست `questions` را از `game.py` پاک کنند.** این لحظه را اعلام کنید:

> «آن لیست را پاک کنید. **بله، پاک.** الان `game.py` هیچ سؤالی نمی‌شناسد — و بازی
> کار می‌کند. سؤال‌ها از این به بعد جای دیگری زندگی می‌کنند.»

# ۴۰ تا ۴۸ — 🎉 لحظه‌ی «خواهر کوچکم»

**⏸ نقطه‌ی توقف ۲:** بازی اجرا می‌شود و پنج سؤال از فایل می‌آیند؟

بعد **این کار را همه با هم و هم‌زمان بکنند** — و شما روی پرده هم انجامش بدهید:

1. `questions.json` را در VS Code باز کنید.
2. یک سؤال تازه اضافه کنید — **بدون اینکه هیچ فایل پایتونی را لمس کنید**.
3. بازی را اجرا کنید.
4. اجرا کنید، اجرا کنید، تا سؤال تازه بیاید (تصادفی است!).

# ۴۸ تا ۶۵ — 🏅 `ScoreBoard`: دفتری که می‌ماند

## دقیقه‌ی ۴۸ تا ۵۲ — سه سؤال قبل از کد

```
۱) دفتر را کِی باز می‌کنیم؟        → اول بازی
۲) کِی در آن می‌نویسیم؟            → آخر مسابقه
۳) اگر دفتر هنوز *وجود نداشته* باشد؟ → ؟؟؟
```

سؤال سوم را جدی بگیرید و بگذارید فکر کنند. جواب: **اولین بار که بازی اجرا می‌شود،
`leaderboard.json` وجود ندارد — و این خطا نیست، طبیعی است.**

> «برنامه‌ی خوب، بارِ اول هم کار می‌کند. پس اول می‌پرسیم *هست؟* بعد می‌خوانیم.»

## دقیقه‌ی ۵۲ تا ۶۵ — کد

```python
class ScoreBoard:
    def __init__(self, path: str = LEADERBOARD_PATH) -> None:
        self._path = Path(path)
        self._data: dict[str, dict[str, int]] = {}

        if self._path.exists():                       # بارِ اول وجود ندارد، و مشکلی نیست
            with open(self._path, encoding="utf-8") as f:
                self._data = json.load(f)

    def record(self, winner: str | None,
               player1: str, score1: int,
               player2: str, score2: int) -> None:
        for name, points in [(player1, score1), (player2, score2)]:
            if name not in self._data:
                self._data[name] = {"wins": 0, "points": 0}
            self._data[name]["points"] += points

        if winner is not None:
            self._data[winner]["wins"] += 1

        self._save()

    def _save(self) -> None:
        with open(self._path, "w", encoding="utf-8") as f:
            json.dump(self._data, f, ensure_ascii=False, indent=2)
```

**چهار نکته:**

- **`"w"`** — «حالت نوشتن. و بدانید: `"w"` فایل قبلی را **کامل پاک می‌کند** و از نو
  می‌نویسد. برای همین است که اول همه‌ی دفتر را در `_data` خواندیم.» این را بگویید،
  وگرنه بعداً کسی فکر می‌کند `"w"` به آخر فایل اضافه می‌کند.
- **`_save` با `_` شروع می‌شود** — «کارِ داخلیِ خودِ دفتردار است. از بیرون کسی
  `_save` صدا نمی‌زند؛ `record` خودش صدایش می‌زند.» *(همان کپسوله‌سازی جلسه‌ی ۴)*
- **`if winner is not None`** — «مساوی هم یک نتیجه است: امتیاز ثبت می‌شود، برد نه.»
- **`_data[name]["points"] += points`** — دیکشنری داخل دیکشنری. یک دقیقه رویش
  بایستید و روی تخته شکلش را بکشید؛ اینجا جای گم‌شدن است.

## ⭐ دقیقه‌ی ۶۰ — نمایشِ `ع` (۲ دقیقه، از دستش ندهید)

**اول `_save` را عمداً ناقص بنویسید** — فقط `json.dump(self._data, f)` — یک مسابقه ثبت کنید،
و بعد `leaderboard.json` را در VS Code باز کنید:

```json
{"علی": {"wins": 0, "points": 30}, "سارا": ...}
```

بگذارید ببینند و بخندند. بپرسید **«اسم علی کجاست؟»**

> «هست! همین است. JSON محافظه‌کار است و پیش‌فرضش این است که ممکن است طرفِ مقابل
> فارسی نفهمد، پس همه‌چیز را به کدِ انگلیسی ترجمه می‌کند.»

حالا `ensure_ascii=False` و `indent=2` را اضافه کنید، دوباره اجرا، دوباره فایل را باز کنید:

```json
{
  "علی": {
    "wins": 0,
    "points": 30
  }
}
```

> «`ensure_ascii=False` می‌گوید *فارسی را فارسی بنویس*. و `indent=2` می‌گوید
> *خوانا بنویس* — چون این فایل را **آدم** هم می‌خواند.»

🌱 و یک جمله برای جلسه‌ی ۸: «و یک فایده‌ی دومِ `indent=2` را جلسه‌ی ۸ می‌بینید،
وقتی git بخواهد نشان بدهد چه چیزی عوض شده.»

# مشکلات رایج امروز

| پیام / نشانه | علت | راه‌حل |
|---|---|---|
| `json.decoder.JSONDecodeError: Expecting ',' delimiter` | ویرگولِ جامانده یا اضافه در JSON | `Shift+Alt+F` روی فایل؛ جایی که مرتب نشد، همان‌جاست |
| `JSONDecodeError: Expecting property name enclosed in double quotes` | گیومه‌ی تک `'` به‌جای `"` — یا ویرگولِ **بعد از آخرین** قلم | JSON فقط `"` قبول می‌کند |
| `UnicodeDecodeError` یا فارسیِ به‌هم‌ریخته | `encoding="utf-8"` جا افتاده | همان جمله‌ی روی تخته: هر `open`، با `encoding` |
| اسم‌ها در فایل `علی` شده‌اند | `ensure_ascii=False` جا افتاده | ✅ عمدی است اگر دقیقه‌ی ۶۰ باشد؛ وگرنه اضافه کنند |
| کل `leaderboard.json` یک خط شده | `indent=2` جا افتاده | اضافه کنند و یک بار دیگر بازی کنند |
| `FileNotFoundError: questions.json` | ترمینال در پوشه‌ی دیگری است، یا فایل جای دیگری ساخته شده | `dir` بزنند؛ فایل باید کنار `game.py` باشد |
| `ModuleNotFoundError: No module named 'storage'` | اسم فایل `storage_skeleton.py` مانده | اسمش را `storage.py` کنند |
| `TypeError: Question.__init__() takes 4 positional arguments but 5 were given` | ⚡ دوبل جلسه‌ی ۴ را نزده‌اند | بلوک دقیقه‌ی ۲۷، یا `engine_complete.py` |
| `ValueError: بانک سؤال 3 سؤال دارد؛ برای یک مسابقه 5 سؤال لازم است` | JSON کمتر از ۵ سؤال دارد (یا یکی خراب است) | ✅ نگهبان کار کرد؛ سؤال اضافه کنند |
| `AttributeError: 'dict' object has no attribute 'text'` | حلقه‌ی تبدیل نوشته نشده — لیستِ دیکشنری مستقیم به `Match` رفته | داخل `QuestionBank.__init__`، حلقه‌ی ساختن `Question` |
| رده‌بندی بعد از بستن برنامه خالی است | `self._save()` در آخر `record` صدا زده نشده | یک خط، آخرِ `record` |
| `KeyError: 'wins'` | فایل `leaderboard.json` دستیِ قبلی، قالبش فرق دارد | پاکش کنند، خودش ساخته می‌شود |
| رده‌بندی هر بار از صفر شروع می‌شود | `if self._path.exists()` نوشته نشده، یا `_data` بعدش بازنویسی می‌شود | ترتیب دو خط در `__init__` |
