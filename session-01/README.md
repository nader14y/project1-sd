# کیت جلسه‌ی ۱ — کیک‌آف

همه‌چیزی که برای برگزاری جلسه‌ی اول لازم دارید.

## از کجا شروع کنم؟

1. **[چک‌لیست آماده‌سازی](prep-checklist.md)** — یک روز قبل و ۱۵ دقیقه قبل از کلاس. با این شروع کنید.
2. **[راهنمای مربی](instructor-guide.md)** — اسکریپت دقیقه‌به‌دقیقه‌ی ۹۰ دقیقه. سند اصلی جلسه.

4. سر کلاس، راهنمای مربی را کنار دستتان باز نگه دارید.

## دموی ابتدای جلسه

```bash
cd ../quiz-battle && ./venv/bin/python main.py --demo
```

`--demo` سؤال‌ها را از پیش می‌چیند تا هر سه قدرت ویژه حتماً دیده شود.
قبلش `leaderboard.json` را پاک کنید تا رده‌بندی از صفر شروع شود.
