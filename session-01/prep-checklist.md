# چک‌لیست آماده‌سازی جلسه‌ی ۱

## یک روز قبل

- [ ] **بازی مرجع را یک‌بار کامل بازی کنید** — نه فقط اجرا؛ یک مسابقه‌ی ۵ راندی تمام کنید
  ```bash
  cd quiz-battle && ./venv/bin/python main.py --demo
  ```
- [ ] `leaderboard.json` را پاک کنید تا رده‌بندی سر کلاس از صفر شروع شود
  ```bash
  rm -f quiz-battle/leaderboard.json quiz-battle/game.log
  ```
- [ ] برگه‌های چاپی را چاپ کنید:
  - `handouts/poster-rules.html` → **۱ نسخه A3 یا A4** (برای دیوار)
  - `handouts/signature-board.html` → **۱ نسخه A3 یا A4** (برای برد کلاس)
  - `handouts/homework.html` → **به تعداد دانش‌آموزان**
  - (هر سه فایل را در مرورگر باز کنید و `Cmd+P` بزنید — برای چاپ تنظیم شده‌اند)
- [ ] **ترکیب تیم‌های ۲ نفره را روی کاغذ بنویسید** — قوی/متوسط. سر کلاس تصمیم نگیرید.
- [ ] فایل‌های `live-code/` را یک‌بار مرور کنید تا حین تایپ زنده گیر نکنید.

## ۱۵ دقیقه قبل از کلاس

- [ ] لپ‌تاپ به پروژکتور وصل و تست شد
- [ ] **فونت ترمینال بزرگ** (۱۸ تا ۲۰pt) — از **ته کلاس** بخوانید، نه از پشت لپ‌تاپ
- [ ] **فونت ویرایشگر بزرگ** (۱۶ تا ۱۸pt) + تم روشن اگر نور کلاس زیاد است
- [ ] پنجره‌ی ترمینال تمام‌صفحه، عرض حداقل ۹۰ ستون
- [ ] پوستر ۵ قانون روی دیوار نصب شد
- [ ] برد قابلیت امضا روی دیوار نصب شد
- [ ] یک پوشه‌ی خالی `quiz-battle` روی دسکتاپ با فایل خالی `game.py` باز در ویرایشگر
- [ ] اعلان‌ها (Notification) خاموش — وسط دمو پیام واتساپ نیاید
- [ ] نوشیدنی/تخته‌پاک‌کن/ماژیک آماده

## ۵ دقیقه اول کلاس (قبل از شروع رسمی)

- [ ] از بچه‌ها بخواهید لپ‌تاپ‌ها را روشن کنند و VS Code را باز کنند
- [ ] در ترمینال بزنند: `python --version` (یا `python3 --version`)
  - جواب نداد؟ تا وسط کلاس با کناردستی‌شان کار کنند و بعد از کلاس نصب کنید
- [ ] هر کس یک پوشه‌ی `quiz-battle` بسازد با فایل `game.py`
