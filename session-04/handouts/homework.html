بخش الف — 🎯 قدرت ویژه‌ی سرقت

  1. به Question اجازه بده قدرت ویژه‌ی "steal" هم داشته باشد.
    اگر امروز ⚡ دوبل را زدیم، ویژگی power_up از قبل هست.
  2. در resolve_round، اگر سؤال "steal" بود: هر جواب درست، ۵ امتیاز از حریف کم می‌کند — ولی هرگز زیر صفر. 
    STEAL = 5

if question.power_up == "steal":
    for player in correct_players:
        rival = ...            # حریفِ این بازیکن کیست؟
        self.scores[rival] = max(0, self.scores[rival] - STEAL)
    راهنمایی ۱: برای پیدا کردن حریف، یک متد کوچک به Match اضافه کن: rival_of(player).
    راهنمایی ۲: max(0, x) یعنی «هرچه شد، از صفر کمتر نشو».
  3. یک سؤال سرقت به لیست game.py اضافه کن و امتحانش کن.
    مطمئن شو امتیاز حریف زیر صفر نمی‌رود — عمداً امتحانش کن!

بخش ج — عضله‌ی commit

  1. کار بالا را در حداقل ۳ commit جدا انجام بده. 
    git add engine.py
git commit -m "Add steal power-up to resolve_round"
قبل از تحویل، چک کن
  • بازی بدون خطا اجرا می‌شود و یک مسابقه‌ی کامل بازی کرده‌ام
  • سرقت کار می‌کند و امتیاز هرگز زیر صفر نمی‌رود
  • در engine.py هیچ print و inputی نیست
  • هر دو سؤال طراحی را روی برگه جواب داده‌ام
  • git log --oneline حداقل ۳ commit تازه نشان می‌دهد
