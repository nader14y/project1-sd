  2. در resolve_round، اگر سؤال "steal" بود: هر جواب درست، ۵ امتیاز از حریف کم می‌کند — ولی هرگز زیر صفر.

بخش ج — عضله‌ی commit

  1. کار بالا را در حداقل ۳ commit جدا انجام بده. 
    git add engine.py
git commit -m "Add steal power-up to resolve_round"
قبل از تحویل، چک کن
  • بازی بدون خطا اجرا می‌شود و یک مسابقه‌ی کامل بازی کرده‌ام
  • سرقت کار می‌کند و امتیاز هرگز زیر صفر نمی‌رود
  • در engine.py هیچ print و inputی نیست
  • در game.py هیچ‌جا match._scores یا match._answers ندارم — فقط score_of و answer_of
  • هر متدی که نوشته‌ام، جنسِ ورودی و خروجی‌اش را دارد (: str و -> int)
  • هر دو سؤال طراحی را روی برگه جواب داده‌ام
  • git log --oneline حداقل ۳ commit تازه نشان می‌دهد
