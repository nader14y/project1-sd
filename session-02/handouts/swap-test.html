تیم دهنده — آماده‌سازی

  1. پوشه‌ی C:\dev\quiz-battle را کپی کنید در C:\dev\swap
  2. در کپی، پوشه‌ی venv را پاک کنید — Shift + Delete
    چرا؟ چون سنگین است و از روی requirements.txt دوباره ساخته می‌شود. چیزی که بازسازی‌شدنی است را دست‌به‌دست نمی‌کنند.
  3. مطمئن شوید در پوشه هم game.py هست و هم requirements.txt
  4. پوشه را به تیم گیرنده بدهید (فلش، پوشه‌ی اشتراکی، یا فقط جای لپ‌تاپ‌ها را عوض کنید)

تیم گیرنده — راه‌اندازی

  1. پوشه را در C:\dev\ بگذارید و ترمینال را همان‌جا باز کنید
  2. این چهار دستور، و نه هیچ دستور دیگری: 
    python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python game.py
  3. یک بازی کامل انجام دهید — از سؤال اول تا امتیاز آخر
