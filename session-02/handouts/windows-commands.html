Quiz Battle · جلسه‌ی ۲ · این برگه روی میزت بماند

۰ قبل از هر چیز: جای پروژه و ترمینال

پروژه باید در C:\dev\quiz-battle باشد — نه روی Desktop و نه داخل OneDrive. (OneDrive پوشه‌ی venv را sync می‌کند و همه‌چیز خراب می‌شود.) مسیر انگلیسی، بدون فاصله.
در VS Code ترمینال را باز کن (Ctrl + `) و مطمئن شو Command Prompt است نه PowerShell: فلش کنار علامت + ← Select Default Profile ← Command Prompt ← ترمینال را ببند و باز کن.

۱ ساخت جعبه‌ابزار پروژه (venv)

cd C:\dev\quiz-battle
python -m venv venv
یک‌بار برای همیشه. پوشه‌ی venv ساخته می‌شود.

۲ فعال‌کردن جعبه‌ابزار — هر بار که ترمینال را باز می‌کنی

venv\Scripts\activate
نشانه‌ی موفقیت: ابتدای خط ترمینال (venv) می‌آید:
(venv) C:\dev\quiz-battle>
👉 تا وقتی این را نمی‌بینی، هیچ دستور pip نزن.

۳ اثبات: پایتون عوض شد

where python
الان اول لیست باید C:\dev\quiz-battle\venv\Scripts\python.exe باشد. یعنی python دیگر پایتونِ داخل پروژه است.

۴ نصب کتابخانه

pip install rich
فقط با (venv) فعال. بیرون از venv نصب نکن.

۵ ساختن لیست خرید پروژه

pip freeze > requirements.txt
⚠️ چک انکودینگ: فایل requirements.txt را در VS Code باز کن و گوشه‌ی پایین-راست را ببین: باید بنویسد UTF-8. اگر نوشت UTF-16 LE، ترمینالت PowerShell بوده — فایل را پاک کن، ترمینال را Command Prompt کن و دستور را دوباره بزن.

۶ راه‌اندازی پروژه روی یک کامپیوتر جدید

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python game.py
چهار خط، و پروژه بالا می‌آید. پوشه‌ی venv را هیچ‌وقت به کسی نمی‌دهی — چون از روی requirements.txt دوباره ساخته می‌شود.

۷ خروج از جعبه‌ابزار

deactivate

ModuleNotFoundError: No module named 'rich' ۹۵٪ مواقع: (venv) فعال نیست. بزن venv\Scripts\activate و دوباره اجرا کن.

running scripts is disabled on this system ترمینالت PowerShell است. Command Prompt کن (بخش ۰).
در PowerShell activate هیچ کاری نکرد .\venv\Scripts\Activate.ps1
(venv) نیامد ولی خطا هم نداد ترمینال را ببند و باز کن، بعد دوباره activate
Access is denied روی پوشه‌ی venv پروژه داخل OneDrive/Desktop است. کل پوشه را به C:\dev منتقل کن.
