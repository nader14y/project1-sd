> این جلسه سه موضوع دارد (venv، rich، git) و متراکم است. هر دقیقه‌ای که سر کلاس صرف
> تنظیمات لپ‌تاپ شود، از بلوک git کم می‌شود. **آماده‌سازی امروز مهم‌تر از همیشه است.**

## 🔴 دو کار حیاتی قبل از کلاس

### ۱. پلن آفلاین برای `pip install rich`

جلسه اینترنت لازم دارد و اگر وسط نصب قطع شود، ۲۵ دقیقه از دست می‌رود.
یک‌بار روی لپ‌تاپ خودتان (ویندوز، همان نسخه‌ی پایتون کلاس):

```bat
mkdir C:\wheels
python -m pip download rich -d C:\wheels
```

خروجی چند فایل `.whl` است (`rich` + `markdown-it-py` + `mdurl` + `Pygments`).
کل پوشه را روی **فلش** بریزید. سر کلاس اگر اینترنت نبود:

```bat
pip install --no-index --find-links=D:\wheels rich
```

- [ ] پوشه‌ی wheels ساخته و روی فلش کپی شد
- [ ] **یک‌بار تست شد** روی یک venv خالی

### ۲. هویت git روی همه‌ی لپ‌تاپ‌ها

**اگر این کار نشود، اولین `git commit` هر دانش‌آموز با خطا متوقف می‌شود** و شما
۱۰ دقیقه‌ی وسط بلوک git را صرف تنظیمات می‌کنید. روی **هر لپ‌تاپ** یک‌بار:

```bat
git config --global user.name "نام دانش‌آموز"
git config --global user.email "ایمیل دانش‌آموز"
git config --global init.defaultBranch main
```

- [ ] روی همه‌ی لپ‌تاپ‌ها انجام شد (یا در ۵ دقیقه‌ی اول کلاس، هم‌زمان)
- [ ] `init.defaultBranch main` ست شد — تا با GitHub جلسه‌ی ۷ هماهنگ باشد و
      هشدار طولانی `git init` نیاید

> ایمیل واقعی لازم نیست؛ همان ایمیلی که برای GitHub استفاده می‌کنند بهتر است.
> اگر ایمیل ندارند، `name@example.com` هم کار می‌کند.

این ۵ دقیقه، ۲۰ دقیقه‌ی وسط جلسه را نجات می‌دهد. همه هم‌زمان بزنند:

```bat

```

- [ ] `python` جواب می‌دهد؟ (اگر Store باز شد → `py --version`؛ اسمشان را یادداشت

      (اگر چیزی برنگرداند، همان‌جا ست کنید — ۳۰ ثانیه‌ی هر نفر)

## چیزهایی که **نباید** انجام دهید

- ❌ `git branch`، `git remote`، GitHub — مال جلسه‌ی ۷
- ❌ `git reset --hard` — خطرناک‌ترین ابزار git را دست تازه‌کار ندهید
- ❌ `git revert` و `git diff` مفصل — امروز فقط `restore` کافی است
- ❌ پنل Source Control در VS Code — امروز با ترمینال کار می‌کنیم تا بفهمند
      زیر دکمه‌ها چه می‌گذرد (از جلسه‌ی ۷ می‌توانند از پنل استفاده کنند)
- ❌ `Panel` و `Table` و `Progress` از rich — مال جلسه‌ی ۱۱
- ❌ ساختن کلاس یا شکستن فایل به چند فایل — مال جلسات ۳ و ۵
- ❌ فرستادن `requirements.txt` یا `.gitignore` آماده در گروه کلاس (خودشان بسازند)
