ترمینال — دستورها و کلیدها

دستورچه می‌کند
dirفایل‌های این پوشه را نشان می‌دهد
cd نام‌پوشهرفتن داخل یک پوشه
cd ..یک پوشه به عقب
clsپاک‌کردن صفحه‌ی ترمینال
code .باز کردن این پوشه در VS Code
کلیدچه می‌کند
↑ / ↓گشتن در دستورهای قبلی
F7لیست کامل دستورهای قبلی (فقط cmd)
Escپاک‌کردن خطی که تایپ کرده‌ای
Ctrl + Shift + `یک ترمینال دوم باز می‌کند
Drag & Dropپوشه را بکش داخل ترمینال → مسیرش تایپ می‌شود
⚠️ یک تله: اگر در ترمینال متنی انتخاب شده باشد، Ctrl+C کپی می‌کند و برنامه را متوقف نمی‌کند. اول یک‌جا کلیک کن تا انتخاب برداشته شود، بعد Ctrl+C.

خواندن پیام خطا — دو سؤال، همین

  File "game.py", line 26          ← کجا؟   (روی این خط کلیک کن!)
    print("✅ درست!")
    ^^^^^
IndentationError: expected an indented block   ← چه شد؟
آخرین خط می‌گوید چه شد. خط File می‌گوید کجا. در ترمینال VS Code اسم فایل و شماره‌ی خط قابل کلیک است. پیام خطا دشمن نیست؛ آدرس است.

میان‌بُرهای بیشتر · هفته‌ای دو تا یاد بگیر، نه همه را یک‌جا

نوشتن کد این‌ها بیشترین وقت را برمی‌گردانند

کلیدچه می‌کندکِی به درد می‌خورد
Shift + Alt + ↓خط را کپی می‌کند زیر خودشاضافه‌کردن سؤال جدید به لیست سؤال‌ها
Alt + ↑ / ↓خط را بالا و پایین جابه‌جا می‌کندوقتی ترتیب دو خط را اشتباه نوشته‌ای
Ctrl + Shift + Kکل خط را پاک می‌کندسریع‌تر از Home، Shift+End، Delete
Ctrl + C / Ctrl + Xبدون انتخاب‌کردن، کل خط را کپی/کات می‌کندلازم نیست اول خط را انتخاب کنی
Tab / Shift + Tabتورفتگی را زیاد/کم می‌کند — روی چند خط انتخاب‌شده هم کار می‌کندوقتی یک بلوک را داخل if یا for می‌بری
Ctrl + Enterیک خط خالی زیر خط فعلی باز می‌کند (بدون رفتن به آخر خط)وسط کد، یک خط جدید می‌خواهی
Ctrl + Backspaceیک کلمهی کامل را پاک می‌کندوقتی اسم متغیر را اشتباه نوشته‌ای
Ctrl + Spaceپیشنهادهای پایتون را نشان می‌دهدیادت نیست اسم متد چه بود؟ چند حرف بنویس و Ctrl+Space

پنجره‌ها جابه‌جایی بین فایل‌ها و پنل‌ها

کلیدچه می‌کند
Ctrl + Pباز کردن سریع فایل — چند حرف از اسمش را بنویس و Enter (از جلسه‌ی ۵ که چند فایل داریم، طلاست)
Ctrl + Shift + Pجعبه‌ی فرمان — هر کاری که یادت نیست کجاست، اینجا اسمش را بنویس
Ctrl + Tabرفتن بین فایل‌های باز
Ctrl + Wبستن تب  ·  Ctrl + Shift + T = برگرداندن تب بسته‌شده
Ctrl + Bنوار کنار را مخفی/نمایان می‌کند (صفحه بزرگ‌تر می‌شود)
Ctrl + Shift + Eپنل فایل‌ها (Explorer)
Ctrl + Shift + Gپنل git (Source Control) — دیدن اینکه چه چیزی عوض شده
Ctrl + = / Ctrl + -بزرگ / کوچک کردن فونت (وقتی چشمت خسته شد)
Alt + Zخطوط بلند را می‌شکند تا همه‌اش دیده شود

باحال این‌ها را نشان بده، بقیه حسودی می‌کنند 😎

کلیدچه می‌کند

Ctrl + Shift + Lهمه‌ی جاهایی که آن کلمه هست را یک‌جا انتخاب می‌کند
Alt + Clickیک مکان‌نمای دوم (و سوم و چهارم…) اضافه می‌کند
F2اسم یک متغیر را در کل فایل یک‌جا عوض می‌کند (نه فقط اینجا)

ویندوز بیرون از VS Code

کلیدچه می‌کند
