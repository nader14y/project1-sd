شش قدم

  1. VS Code را باز کن
  2. File → Open Folder → C:\dev\quiz-battle
    پوشه، نه فایل! چک: بالای نوار کنار باید بنویسد QUIZ-BATTLE
  3. ترمینال را باز کن: Ctrl + `
  4. venv\Scripts\activate
    💡 فلش بالا ↑ را امتحان کن — اگر قبلاً این دستور را زده باشی، خودش می‌آید.
  5. python game.py
    💡 python ga بنویس و Tab بزن — بقیه‌اش را خودش کامل می‌کند.
  6. یک سؤال جواب بده، بعد Ctrl + C برای توقف
