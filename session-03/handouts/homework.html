بخش الف — عضله‌ی ابزار 💪

  1. مسابقه‌ی راه‌اندازی را سه بار در خانه انجام بده و زمان هر بار را بنویس:
    دور ۱: ______ ثانیه  ·  دور ۲: ______ ثانیه  ·  دور ۳: ______ ثانیه
    شش قدمش روی برگه‌ی مسابقه است. هدف: زیر ۳۰ ثانیه.
  2. یک‌بار عمداً فایل را بدون ذخیره‌کردن اجرا کن و نقطه‌ی سفید را ببین.
    اگر Auto Save روشن است، موقتاً خاموشش کن، ببین، و دوباره روشن کن.

بخش ب — عضله‌ی commit

  1. بازی را کمی بهتر کن — هر چیزی که خودت دوست داری. مثلاً:
    ۳ سؤال جدید · رنگ بهتر برای منو · پیام تشویق بعد از جواب درست · نشان دادن امتیاز فعلی بعد از هر سؤال
  2. این کار را در حداقل ۵ commit جدا انجام بده — نه یک commit بزرگ آخر شب. 
    git add .
git commit -m "Add three geography questions"
    هر تغییر کوچکِ کارکننده = یک commit. پیام: فعل امری + چه چیزی + کوتاه.
  3. اسکرین‌شات این دستور را بگیر و بیاور: 
    git log --oneline
    یادت باشد: صفحه با کلید q بسته می‌شود، ترمینال هنگ نکرده.
  4. یک‌بار عمداً فایلت را خراب کن، ذخیره کن، و برش گردان: 
    git restore game.py
    این را انجام بده حتی اگر لازمش نداری — دستت باید عادت کند.
قبل از تحویل، چک کن
  • پروژه را با Open Folder باز می‌کنم (نه با دابل‌کلیک روی فایل)
  • git log --oneline حداقل ۵ خط با پیام معنادار نشان می‌دهد
  • در git status هیچ اثری از پوشه‌ی venv نیست
  • بازی بدون خطا اجرا می‌شود
  • یک‌بار git restore را تجربه کردم
🔮 برای جلسه‌ی بعد
هفته‌ی بعد سنگین‌ترین و مهم‌ترین جلسه‌ی فنی دوره است: بازی از تک‌نفره تبدیل می‌شود به دونفره. آخر آن جلسه، اولین مسابقه‌ی واقعی‌ات را با هم‌تیمی‌ات بازی می‌کنی. پس پروژه‌ات باید سالم و commit شده باشد — و مسابقه‌ی راه‌اندازی را تمرین کرده باشی، چون آن جلسه به هر دقیقه‌اش نیاز داریم.
