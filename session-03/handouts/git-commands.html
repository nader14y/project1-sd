🌿 برگه‌ی دستورها — git

Quiz Battle · جلسه‌ی ۲ · این برگه روی میزت بماند
git دکمه‌ی save بازی است. هر commit یعنی یک save. هر جا save کردی، هر وقت خواستی برمی‌گردی — حتی اگر فایل را بسته باشی، کامپیوتر را خاموش کرده باشی، یا یک هفته گذشته باشد.
پوشه‌ی کارworking
◀── add ──
سبد خریدstaging
◀── commit ──
آلبوم عکسhistory

۰ یک‌بار برای همیشه (روی هر کامپیوتر تازه)

git config --global user.name "نام تو"
git config --global user.email "ایمیل تو"
git می‌خواهد بداند هر save را چه کسی زده. بدون این، اولین commit خطا می‌دهد.

۱ شروع کردن پروژه (فقط یک‌بار برای هر پروژه)

git init

۲ چه چیزی عوض شده؟

git status
قرمز = هنوز در سبد نیست · سبز = در سبد است، آماده‌ی عکس‌گرفتن

۳ چیزهایی که git اصلاً نباید ببیند

یک فایل به اسم .gitignore بساز (با نقطه‌ی اول، بدون .txt) و داخلش:
venv/
__pycache__/
چرا venv؟ چون سنگین است و از روی requirements.txt دوباره ساخته می‌شود. چیزی که بازسازی‌شدنی است در آلبوم جا نمی‌گیرد.

۴ ثبت یک save

git add .
git commit -m "Add colored quiz with 5 questions"
add . یعنی «همه‌ی تغییرها را بریز در سبد». بعد commit از سبد عکس می‌گیرد.

۵ دیدن آلبوم

git log --oneline
⚠️ ترمینال هنگ نکرده! خروجی git log در یک صفحه‌ی مخصوص باز می‌شود. با فلش بالا/پایین حرکت کن و با کلید q ببندش.

۶ 🎉 برگرداندن فایل خراب

git restore game.py
این همان جادوی امروز است. هر بلایی سر فایل آورده باشی، به آخرین save برمی‌گردد. کاری که Ctrl+Z نمی‌توانست بکند.
