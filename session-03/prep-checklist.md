## 🔴 کار حیاتی: هویت git روی همه‌ی لپ‌تاپ‌ها

**اگر این نشود، اولین `git commit` هر دانش‌آموز با خطا متوقف می‌شود** و ۱۰ دقیقه‌ی
وسط جلسه صرف تنظیمات می‌شود. روی **هر لپ‌تاپ** یک‌بار:

```bat
git config --global user.name "نام دانش‌آموز"
git config --global user.email "ایمیل دانش‌آموز"
git config --global init.defaultBranch main
```

- [ ] روی همه‌ی لپ‌تاپ‌ها انجام شد (یا در ۵ دقیقه‌ی اول کلاس، هم‌زمان با هم)
- [ ] چک سریع: `git config --global user.name` باید چیزی برگرداند

> ایمیل واقعی لازم نیست؛ ولی اگر همان ایمیل GitHub باشد، جلسه‌ی ۷ راحت‌تر می‌شود.
> `init.defaultBranch main` هشدار طولانی `git init` را حذف می‌کند و با GitHub هماهنگ است.

## چیزهایی که **نباید** انجام دهید

- ❌ **سخنرانی درباره‌ی VS Code.** هر مفهوم = درد + میان‌بُر + تمرین فوری. سه دقیقه، نه ده دقیقه.
- ❌ **Auto Save را از اول روشن نکنید** — اول درد نقطه‌ی سفید، بعد Auto Save
- ❌ `git branch`، `git remote`، GitHub — مال جلسه‌ی ۷
- ❌ `git reset --hard` — خطرناک‌ترین ابزار git را دست تازه‌کار ندهید
- ❌ `git revert` و `git diff` مفصل — امروز `restore` کافی است
- ❌ **زدن دکمه‌های Stage و Commit در پنل Source Control** — امروز فقط *نگاه‌کردن*
      به آن پنل؛ دستورها در ترمینال تایپ می‌شوند تا بفهمند زیر دکمه‌ها چه می‌گذرد
- ❌ میان‌بُرهای فانتزی VS Code (multi-cursor، snippet، emmet) — امروز فقط چیزهایی که
      هفته‌ی پیش وقت‌تان را خوردند
